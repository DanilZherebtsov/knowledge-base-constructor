# knowledge-base-constructor

**Идея — LLM-вики.** Источники проекта однократно компилируются в постоянную связанную вику; дальше агент отвечает, читая её, а не выводя одно и то же из сырых документов заново при каждом вопросе.

Готовый проект для работы с ИИ-агентом: правила, память проекта (`wiki/`), план работ, порядок работы с решениями, кодом, презентациями и ролями — всё уже на месте, ничего подключать не надо. Один и тот же проект работает в **Claude Code**, **Codex** и **Qwen Code**.

- **Как скачать:** кнопка **Code → Download ZIP** на странице [публичного зеркала](https://github.com/DanilZherebtsov/knowledge-base-constructor) — распакуется папка `knowledge-base-constructor-main`: она и есть проект, переименуй её и открывай. Переноси папку только целиком: часть файлов в ней скрыта (`.claude/`, `.codex/`, `.qwen/`). На Mac распаковывай двойным щелчком: `unzip` в Терминале обрывается на русских именах файлов. Не клонируй (`git clone`): в архиве нет служебных файлов зеркала (`README.md`, `CHANGELOG.md`, `versions.json`, `migrations/`), а клон тянет их и связывает папку с этим репозиторием.
- **Нужен `python3`** (Mac, Linux) — на нём работают автоматические проверки проекта: напоминания, защита присланных документов, проверка ответов. На Windows проект не проверялся: команды проверок записаны для Mac и Linux и там, скорее всего, не запустятся. Правила проекта при этом действуют — агент работает по ним, только без автоматических проверок.
- **Правила проекта — в `AGENTS.md`.** Рядом лежит `CLAUDE.md` из одной строки `@AGENTS.md`: через неё правила читает Claude Code. В других программах он не используется; удалять его не нужно.
- **Первая настройка — один раз, до первого разговора:**
  - **Claude Code** (терминал, VS Code, JetBrains, вкладка Code) — ничего настраивать не нужно.
  - **Claude Desktop** (проект, не вкладка Code) — создай проект и открой его настройки (**Project settings**): **Environment → Pre-approved folders → Add** — выбери папку проекта; **Memory → Project instructions** — вставь строку «Перед первым ответом в каждом чате прочитай AGENTS.md из папки проекта и следуй ему; не можешь открыть файл — скажи об этом. Записывай в файлы этой папки, не в память приложения (MEMORY.md).» Автоматические проверки проекта в Claude Desktop не работают — правила держатся текстом.
  - **Codex** — при первом открытии папки Codex спросит, доверять ли ей: выбери «Trust and continue», не «Open restricted». Затем набери `/hooks` и одобри проверки этого проекта, перезапусти Codex. Без доверия Codex читает только первые 32 КиБ правил, а они больше — агент скажет, как это исправить. Проверка ответов после части ответов делает короткий отдельный запуск Codex: при входе по ключу API это тратит деньги, при входе по подписке — её лимиты; не нужна — скажи агенту «выключи проверку памяти».
  - **Qwen Code** — открой его в папке проекта в окне (не `qwen -p`) и одобри проверки проекта, когда он спросит, или набери `/hooks`. Одобрение снимается после обновлений, меняющих проверки, и после правки файла `.env` в проекте — тогда одобри заново. Если в своих настройках Qwen Code ты включил доверие к папкам — доверь и эту папку: иначе он молча не читает ни правила, ни проверки проекта.
- **Открыть:** папку — в своей программе, и просто начни разговор: агент спросит, чем будем заниматься, и запишет ответ в описание проекта.
- **Можно работать в нескольких программах по очереди.** Всё знание проекта — обычные файлы (`wiki/`, `STATE.md`, правила, документы), их читает любая из трёх. Перед сменой программы скажи «передай в новый чат»: история разговора и встроенная память программы не переезжают. В новой программе — один раз её первая настройка.
- **Свои правила** проси записывать без названий программ — тогда их исполнит любая; особенность одной программы агент запишет в её файл в `methodology/среда/`.
- **Проект на версии 2.x:** скажи «сделай профилактику» — агент предложит переход на 3.0.0 и проведёт его: твои правки сохранятся, переход откатывается одной командой; в конце агент скажет, что сделать в программах (строка в Claude Desktop, одобрение проверок в Codex и Qwen Code). Для перехода нужна программа с терминалом и сетью — Claude Code, Codex или Qwen Code; в Claude Desktop агент попросит открыть проект там. **Проект на версии 1.x** — так же: сначала переход на 2.0.0, затем, на следующей профилактике в новом чате, — на 3.0.0. Файлы 1.x (`base/`, `mechanics/`, `START-HERE.md`) — по тегу `v1-final`.
- **Что дальше:** в любой момент напиши `help` — агент покажет, что умеет в этом проекте; особенности каждой программы — в `methodology/среда/`. Раз в неделю — «сделай профилактику»: проверка памяти проекта и предложение обновиться, если вышла новая версия.
- **Версии:** одна на весь проект и все программы, [`versions.json`](versions.json); что изменилось — [`CHANGELOG.md`](CHANGELOG.md). Проект несёт номер своей версии в строке 3 `AGENTS.md`; обновление сохраняет твои правки.
