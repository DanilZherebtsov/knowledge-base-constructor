# knowledge-base-constructor

**Идея — LLM-вики.** Источники проекта однократно компилируются в постоянную связанную вику; дальше Claude отвечает, читая её, а не выводя одно и то же из сырых документов заново при каждом вопросе.

Готовый проект для работы с Claude: правила, память проекта (`wiki/`), план работ, порядок работы с решениями, кодом, презентациями и ролями — всё уже на месте, ничего подключать не надо.

- **Как скачать:** кнопка **Code → Download ZIP** на странице [публичного зеркала](https://github.com/DanilZherebtsov/knowledge-base-constructor) — распакуется папка `knowledge-base-constructor-main`: она и есть проект, переименуй её и открывай. Файлы из неё не перекладывай: часть из них скрыта (`.claude/`). На Mac распаковывай двойным щелчком: `unzip` в Терминале обрывается на русских именах файлов. Не клонируй (`git clone`): в архиве нет служебных файлов зеркала (`README.md`, `CHANGELOG.md`, `versions.json`, `migrations/`), а клон тянет их и связывает папку с этим репозиторием.
- **Проект на версии 1.x** делать ничего не должен: профилактика предложит переход. Файлы 1.x (`base/`, `mechanics/`, `START-HERE.md`) — по тегу `v1-final`.
- **Открыть:** папку — в Claude Code или Claude Desktop и просто начни разговор (в проекте Claude Desktop — сначала шаг ниже): Claude спросит, чем будем заниматься, и запишет ответ в описание проекта.
- **Только Claude Desktop:** создай проект и открой его настройки (**Project settings**): **Environment → Pre-approved folders → Add** — выбери папку проекта (в ней лежит `CLAUDE.md`); **Memory → Project instructions** — вставь строку «Перед первым ответом в каждом чате прочитай CLAUDE.md из папки проекта и следуй ему; не можешь открыть файл — скажи об этом. Записывай в файлы этой папки, не в память приложения (MEMORY.md).» В VS Code, в Claude Code и во вкладке Code этот шаг не нужен.
- **Что дальше:** в любой момент напиши `help` — Claude покажет, что умеет в этом проекте. Для автоматических проверок нужен `python3`. Раз в неделю — «сделай профилактику»: проверка памяти проекта и предложение обновиться, если вышла новая версия.
- **Версии:** одна на весь проект, [`versions.json`](versions.json); что изменилось — [`CHANGELOG.md`](CHANGELOG.md). Проект несёт номер своей версии в строке 3 `CLAUDE.md`; обновление сохраняет твои правки.
