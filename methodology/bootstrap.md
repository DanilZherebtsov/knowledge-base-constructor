# Bootstrap — восстановление структуры

Отсутствие папок типов вики, `specs/`, `data/`, `scripts/`, код-папки — норма, не повод восстанавливать: они появляются с первой страницей или по первому поводу.

Проект приходит готовым: `CLAUDE.md`, `HELP.md`, `STATE.md`, `methodology/`, `roles/`, `.claude/` (машинерия среды: `SessionStart`-хук форсинга стартовых проверок, служебная строка о согласии и правка ответа по слову «проще», оценщик готового ответа и стиль ответов `output-styles/plain.md`), заготовки `wiki/index.md`, `wiki/log.md`, `input/`, `raw/`, `output/`. Этот файл — только восстановление: запускается, когда чего-то из этого списка нет или файл разрушен, или по просьбе («восстанови структуру»). **Никогда** из `query`/`lint` — они только сообщают. Хуки и стиль ответов восстанавливает профилактика ([lint.md](lint.md), «Проверка памяти проекта не работает», «Стиль ответов не включён»).

## Восстановить (чего нет, не перезаписывая существующее)

- `input/.gitkeep` — свалка для входящих (человек кидает сюда любые материалы; Claude раскладывает по `raw/` на ingest, человеку подпапки знать не нужно).
- `raw/.gitkeep` — пустой; подпапки заранее не заводятся (см. «Что не создаётся заранее»).
- `wiki/index.md` (`# Wiki Index`) и `wiki/log.md` (`# Wiki Log`). Папки типов вики — не создаются: тип появляется с первой страницей.
- `output/.gitkeep` — **документы проекта и рабочие результаты**; пустой. Подпапки заранее не заводятся: место появляется, когда его назовёт человек ([lint.md](lint.md), «Места в `output/`»).
- `STATE.md` — семь разделов с пометкой `_пусто_` ([state-rules.md](state-rules.md), «Структура»); строка `_Обновлено: YYYY-MM-DD_` — с сегодняшней датой.

## Что не создаётся заранее

- **Роли** — заранее не заводим; любую роль можно создать в любой момент «создай роль <название>» (см. [roles.md](roles.md)), а по желанию заранее закинуть в `input/` описание роли и материалы для её работы — тогда она создастся сразу квалифицированно.
- **Код-папка** — пустой не заводится. Появляется, когда код реально приходит или решено делать его с нуля, с уведомлением человеку одной строкой ([software-engineering.md](software-engineering.md)). `specs/` — с первой спекой, `data/` и `scripts/` — по первому поводу.
- **`BRAND.md`** — сам не заводится вообще. Появляется только **по согласию человека**: после того как он принял первую визуальную работу, Claude один раз предлагает сохранить согласованный стиль на будущее. Отказ — нормальный исход, файла просто нет. Пришёл готовый фирстиль от клиента — файл заводится сразу при его разборе ([ingest.md](ingest.md)): согласие уже дано этим действием. Пишется всегда **из построенного**, а не заранее.
- **`tmp/`** — временное: то, что пишется для следующего шага работы, а не человеку (перечень — дерево «Архитектура» `CLAUDE.md`); пустым не создаётся, появляется при первой такой записи. Под git — добавить `tmp/` в `.gitignore` в момент создания, до первой записи внутрь.
- **`archive/`** — устаревшее из `tmp/`, что не стоит удалять; пустым не создаётся, появляется при первом выпуске ([lint.md](lint.md)). Под git — добавить в `.gitignore` строку `/archive/` (с ведущим слэшем: строка `archive/` спрятала бы и `output/archive/`) в момент создания, до переноса первого файла.
- **`output/archive/`** — отработанное из `output/`; пустым не создаётся, появляется с первым переносом вместе с журналом `index.md` ([lint.md](lint.md), «Перенос в `output/archive/`»).
- **`BACKLOG.md`** — отложенное; заводится при первом таком пункте ([state-rules.md](state-rules.md)).
- **Подпапки `raw/`** — заранее не заводятся: пустая папка под источник, которого ещё нет, — угадывание. Первый материал раскладывается на ingest, тогда же появляется подпапка и вписывается в дерево «Архитектура» `CLAUDE.md` ([ingest.md](ingest.md), шаг 2). Человеку подпапки знать не нужно — он кидает в `input/`.
- Папки сверх минимума — по смыслу, когда появится потребность (правило «Структура растёт по мере надобности» в [CLAUDE.md](../CLAUDE.md)); в `output/` местом становится только папка, которую назвал человек.

После восстановления — если проект под git (правило «git опционален» в `CLAUDE.md`) — коммит `bootstrap: восстановление структуры`; иначе пропускается.
