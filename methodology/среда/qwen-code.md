# Qwen Code — особенности программы

Файл среды: что в этом проекте устроено иначе, когда он открыт в Qwen Code. Правила проекта — в [AGENTS.md](../../AGENTS.md); здесь только то, чем Qwen Code отличается от других программ. Наблюдения — с датой и версией: поведение программы может измениться.

## Как подключаются правила

Qwen Code читает `AGENTS.md` сам: это его файл правил по умолчанию (настройка `context.fileName`). `CLAUDE.md` он не читает: это строка для Claude Code, удалять её не нужно.

- **Личная настройка `context.fileName` без `AGENTS.md`** — правила проекта не загружаются. Проверка среды при старте говорит человеку, что добавить.
- **Доверие к папкам.** По умолчанию выключено. Если человек включил его в своих настройках (`security.folderTrust.enabled: true`), а эту папку не доверил, — Qwen Code **молча** не читает ни правила, ни настройки проекта, ни его проверки (проверено на 0.26.1, 26.10.2026). Изнутри это не видно никому — ни тебе, ни проверкам; поэтому об этом сказано человеку в README зеркала.
- **Запущен не в папке проекта** — проверки проекта Qwen Code берёт только из папки запуска. Проверка среды говорит человеку открыть Qwen Code в папке проекта.

## Первая настройка

Один раз на проект: открыть Qwen Code в папке проекта в окне (не `qwen -p`) и **одобрить проверки проекта**, когда он о них спросит, или набрать `/hooks`. Без одобрения проверки не загружаются — в выводе Qwen Code строка «Project hooks in .qwen/settings.json were not loaded: they are not approved for this folder» (проверено на 0.27.4, 16.11.2026). Предупреждение Qwen Code, что постоянный контекст длиннее 10 000 токенов (`Loaded always-on context … more than 10,000 tokens`), для этого проекта ожидаемо: правила такого размера — спросит человек, так и сказать. Что именно показывает окно одобрения — по коду Qwen Code, запуском не проверено. Нужен `python3`.

## Настройки и проверки проекта

- **Файлы настроек:** `.qwen/settings.json` — проверки проекта и стиль ответов; `.qwen/output-styles/plain.md` — файл стиля. Личные — `~/.qwen/settings.json`; решения об одобрении — `~/.qwen/hookApprovals.json`.
- **Проверки проекта** — записи в `.qwen/settings.json`: `SessionStart` → `hooks/start.py`; `UserPromptSubmit` → `hooks/consent.py`; `PreToolUse` (`write_file|edit|notebook_edit|run_shell_command|monitor`) → `hooks/raw_guard.py`; `Stop` (таймаут 90 с) → `hooks/judge.py`. Команда — `python3 "$QWEN_PROJECT_DIR/hooks/<скрипт>.py" --program qwen`, с проверкой `python3` впереди и `|| true` в конце.
- **Выключить все проверки разом** — отклонить их в `/hooks` (отдельного выключателя проекта мы не проверяли).
- **Одобрение — по содержимому** блока проверок в `.qwen/settings.json` и файла `.env` проекта. Изменилось одно из них (обновление проекта, правка `.env`) — одобрение снято, проверки не загружаются, пока человек не одобрит их заново. Правка самих скриптов `hooks/` одобрения не снимает: команды записей между версиями не меняются. Отклонённые проверки Qwen Code больше не предлагает — включить их можно только в `/hooks`.
- **Страж `raw/`** видит запись и правку файлов, команды шелла и `monitor`; команды проверяет по шаблонам — поэтому правило «`raw/` неизменяем» главнее стража.

## Стиль ответов

Ключ `"outputStyle": "plain"` в `.qwen/settings.json` и файл `.qwen/output-styles/plain.md` (тот же текст, что у Claude Code). Включён — в твоих инструкциях есть раздел «Стиль ответов: сообщение из двух частей». Раздела нет — читай `.qwen/output-styles/plain.md` в начале чата и после сжатия контекста. Варианта «только для вас» у Qwen Code нет: личный файл настроек `~/.qwen/settings.json` общий для всех проектов человека — на вопрос «для всей команды или только для вас» сказать это и предложить выбор «для всей команды» или «не ставить».

## Субагенты без истории разговора

Инструмент `agent` с именованным типом субагента (встроенным общим; не `fork`) запускает его без истории разговора — типа, кроме `fork`, в списке нет: проверяющих не запустить, сказать человеку; всё нужное ему — в тексте задания; `fork` передаёт весь разговор, и независимым он не будет (по коду Qwen Code 0.26.1; запуском в этой версии проекта не проверено). В задании проверяющему прямо пиши «ничего не создавай и не меняй».

## Запуск без окна

`qwen -p` — безоконный запуск: человека в разговоре нет, вопросов не задавать. В выводе `-p` — только последний ответ хода (наблюдение 16.11.2026).

## Сеть при обновлении

Шелл Qwen Code обычно с сетью (песочница по умолчанию выключена). Без сети — шаг 1 проверки обновлений сделать инструментом чтения страниц `web_fetch`; встроенный веб-поиск для неё запрещён. Шагам 2–8 нужен `git` с сетью — человеку: «запусти Qwen Code с доступом в сеть (без песочницы) — там обновление пройдёт».

## Оценщик ответа и его цена

`hooks/judge.py` после части ответов запускает отдельный короткий `qwen -p` (безопасный режим, без записи разговора, один ход) — той же моделью, что настроена у человека. Цена — как у одного короткого запроса к этой модели; на локальной модели ответ может прийти позже, вплоть до таймаута 90 с.

## Встроенная память программы

Встроенная авто-память Qwen Code после каждого ответа делает отдельный запрос к модели и может записать заметку в свою папку `~/.qwen/projects/…/memory/` (наблюдение 16.11.2026, 0.27.4). Инструмент `save_memory` пишет в личный файл правил человека `~/.qwen/QWEN.md`. И то и другое — не память проекта: знание проекта — только в `wiki/` через ingest; `save_memory` для него не используй. Авто-память включена (по умолчанию так) — проверка среды один раз на проект говорит об этом человеку и как выключить: `"memory": {"enableManagedAutoMemory": false}` в настройках Qwen Code.

## Удаление, когда программа не даёт

Общий порядок — [lint.md](../lint.md), «Удаление, когда среда не даёт». Qwen Code спрашивает человека перед командами и правками в своём окне подтверждения; отказ в окне — п. 4 общего порядка. В режиме, где Qwen Code не спрашивает и запрещает, — сказать человеку: «Удалить не дал Qwen Code. Разреши это в окне подтверждения или смени режим подтверждений на тот, где он спрашивает, и напиши „удали“». Запуском не проверено.

## Запись настроек, когда программа не даёт

Общий порядок — [lint.md](../lint.md), «Запись проверок и настроек программ»; здесь — Qwen Code.

- **После записи `.qwen/settings.json`** одобрение снято (оно по содержимому): попросить человека открыть Qwen Code в папке проекта в окне и одобрить проверки заново или набрать `/hooks` (п. 6 общего порядка).
- Отказ записи в окне подтверждения — что нужно от человека (п. 2 общего порядка): разрешить запись в окне или сменить режим подтверждений.
