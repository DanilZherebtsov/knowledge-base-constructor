# Миграция 0005 — стиль ответов из двух частей и весь переход на base@49

> **Исполняется агентом ВНУТРИ боевого репозитория инстанса** с отпечатком `base@48`. Это **единственный путь** перехода 48→49: прочие блоки записи `## base@49` журнала (если появятся) эта миграция тоже проводит — шаг 6. По заголовкам журнала base@49 не принимать: профилактика сверяет номера версий, и версия, принятая наполовину, вторую половину больше не догонит. Источник — публичное зеркало (`constructor/base/`). Знание — ADR-0061.

## Что меняется и главный инвариант

1. **`.claude/`** — новый файл `output-styles/plain.md` (стиль ответов: сверху — что решить сейчас, ниже строки «Остальное — решать сейчас не нужно:» — остальное); строка `"outputStyle": "plain"` в `settings.json` (или, по выбору человека, в `settings.local.json`); новые версии `hooks/consent_nudge.py` (правка ответа по одному слову «проще») и `hooks/judge.py` (вопрос человеку ищется в верхней части ответа).
2. **Проза** — `CLAUDE.md` (абзацы «На языке человека» и «Проще», «Закрой все запросы», сверка понимания, строка дерева `.claude/`, «Просьба решена»), `methodology/human-language.md`, `methodology/lint.md`, `methodology/bootstrap.md`; `HELP.md` — с «да» человека (шаг 9).

> **Инвариант миграции.** Меняется только стандартный слой: `.claude/` (чужие хуки и ключи — байт-в-байт), `CLAUDE.md`, `methodology/*.md`, `HELP.md` (с «да»), отпечаток, одна строка журнала в `wiki/log.md`; при выборе «только у меня» — ещё `.claude/settings.local.json` и, если нужно, `.git/info/exclude` (оба не идут в коммит). Тела страниц `wiki/`, `raw/`, `STATE.md`, рабочие слои — байт-в-байт. **Каждый шаг идемпотентен:** уже сделанное — пропустить; прерванную миграцию можно запустить заново.

## Шаг 1. Входное состояние

Отпечаток (строка 3 `CLAUDE.md`) — `base@48`; иначе сначала догнать ленту до 48. Затем:
- **Среда.** Не Claude Code (Claude Desktop, Cowork) — выполнить шаги 2 и 5–10; строку `outputStyle` и хуки не трогать (там они не загружаются). Журнал: репозиторий не общий — `## [YYYY-MM-DD] настройка | стиль: не пропустила среда` (правило «На языке человека» будет само читать файл стиля); общий — сначала вопрос «включать ли новый вид ответов для всей команды» (только для себя здесь включить нельзя — сказать): да — `… | стиль: не пропустила среда`, нет — `… | стиль: не ставим`, без ответа — `… | стиль: ждёт ответа`.
- `.claude/settings.json` есть → ветка B; нет (человек убрал папку) → ветка A.
- **`outputStyle` уже где-то стоит:**
  - в `.claude/settings.local.json`, другое значение — выбор человека: одной фразой сказать, что стиль проекта у него не включится; ключи не трогать;
  - в `~/.claude/settings.json` (личный стиль X) — сказать «ваш стиль X в этом проекте сменится на стиль проекта» и спросить; «оставь мой» — в общем репозитории записать `"outputStyle": "X"` в его `.claude/settings.local.json` (не в коммит, как в шаге 3), общий журнал не трогать; в своём (один автор) — строку не писать, журнал `… | стиль: не ставим`;
  - в проектном `settings.json` уже `plain`, а человек этого не выбирал (привезла миграция 0003 или сборка) — в общем репозитории всё равно задать вопрос шага 3.
- **Общий репозиторий:** в `git log --format=%ae | sort -u` больше одного автора (адреса noreply не считать); неглубокий клон — считать общим.

## Шаг 2. Файл стиля

Скопировать из зеркала `base/.claude/output-styles/plain.md` → `.claude/output-styles/plain.md`. Уже лежит такой же — пропустить; лежит другой текст (человек правил или это его собственный стиль с тем же именем) — показать и спросить, молча не перезаписывать. Файл кладётся в любой среде. Копирование не прошло (защита среды) — по разделу «Запись хуков…» `methodology/lint.md`; без файла шаг 3 не выполнять.

## Шаг 3. Строка `outputStyle` (только Claude Code)

Только если `.claude/output-styles/plain.md` на месте (шаг 2).

- **Общий репозиторий — сначала вопрос** «для всей команды или только для вас» с ценой: всем — строка в общий `settings.json`, личный стиль каждого в этом проекте перекроется; только вам — строка в `.claude/settings.local.json` той папки, где открыт этот чат (не той рабочей копии, где идёт правка), действует только на этом компьютере. Без ответа строку не писать, журнал `… | стиль: ждёт ответа`.
- **Ветка A** (нет `settings.json`) — создать `.claude/settings.json` только с `{"outputStyle": "plain"}`; хуки без вопроса не восстанавливать — их убрал человек.
- **Ветка B** — добавить ключ на верхний уровень, **не перезаписывая файл** и не трогая прочие ключи. В проектном файле уже другое значение — спросить.
- **«Только вам»** — ключ в `.claude/settings.local.json` (слить с тем, что там есть, например `permissions`); `git check-ignore .claude/settings.local.json` — не в игноре → строкой в `.git/info/exclude`, общий `.gitignore` не трогать; журнал `## [YYYY-MM-DD] настройка | стиль: только у меня`. Файла `plain.md` в этой папке ещё нет (правка идёт в другой рабочей копии и придёт после слияния) — ключ записать в шаге 10, когда файл появится.
- **Отказ среды** — `methodology/lint.md`, «Запись хуков, когда автоматический режим не даёт», с литералами стиля: попытка → вопрос «впиши проверки» → повтор → просьба переключить режим → повтор; не вышло — `… | стиль: не пропустила среда`; отказ человека — `… | стиль: не ставим`. Строка не записалась — одной фразой: агент будет сам читать файл стиля по правилу «На языке человека», без напоминания перед каждым ответом.

## Шаг 4. Хуки (только Claude Code)

- `.claude/hooks/consent_nudge.py`: совпадает с файлом зеркала — пропустить. `git hash-object` = `ff883ba8c3c3e472dfae4c62fd44ad1a13db5074` (версия base@43–48) и в `settings.json` есть его запись `UserPromptSubmit` — заменить из зеркала, `chmod +x`. Файла или записи нет (человек убрал) — не ставить и не спрашивать. Хэш другой — файл правили: показать отличия от зеркала и спросить. Без git — старая версия узнаётся по тому, что в ней нет строки `[plain]` и других отличий от прежнего файла зеркала.
- `.claude/hooks/judge.py`: то же; прежняя версия — `f33169cd8e2877389ad0f3b79dfb5947093f3d54`, запись — `Stop`; без git — в старом файле нет `def asks_human`.
- Отказ среды — старые файлы остаются (работают в прежнем виде), сказать одной фразой; литерал не нужен.

## Шаг 5. Проза

По заголовкам, сохраняя свои дописки проекта:
- `CLAUDE.md`: блок «На языке человека» (абзац, четыре вопроса и абзац «Точность не выбрасывай») → абзацы «На языке человека» и «Проще» из зеркала; «Закрой все запросы» — фраза о нескольких просьбах; гейт сверки — пункт (3) и фраза «Форма — стиль ответов…» после (4); строка дерева `.claude/`; «Просьба решена» — место предложения записать («последней строкой верхней части ответа»), перенос при вопросе в верхней части, «ок» в «Согласии», «Оценщик» (вопрос в верхней части; служебные строки), «Длинная работа».
- `methodology/human-language.md`, `methodology/lint.md`, `methodology/bootstrap.md` — файлом зеркала, если проект их не менял; менял — по смыслу, переносом отличий новой версии зеркала от прежней.

## Шаг 6. Остальные части base@49

Прочие блоки записи `## base@49` журнала, если они есть, — по их «Как принять».

## Шаг 7. Свои правила формы сообщения

Грепом по `CLAUDE.md` вне стандартных блоков, по `.claude/skills/` и `roles/`: `Подробност|Первая строка ответа|в конце сообщения|последней строкой|На языке человека|четыре вопрос` (в англоязычном проекте — `Details|first line of the reply|at the end of the message|last line|In the human's language|four questions`); в `roles/` — ещё разделы «Тон и формат» целиком. Человеку — списком, с предложенной заменой («в нижней части сообщения», «первой фразой» и т. п.); без «да» не править.

## Шаг 8. Проверить

- diff — только стандартный слой; `settings.local.json` и `.git/info/exclude` (при «только у меня») — в коммит не идут;
- `.claude/settings.json` (и `settings.local.json`, если трогали) — валидный JSON;
- хук «проще» — только если он заменён в шаге 4 (иначе пункт пропустить и назвать причину): `echo '{"prompt":"<ide_opened_file>x</ide_opened_file>\nпроще"}' | python3 .claude/hooks/consent_nudge.py` — две строки, вторая начинается с `[plain]`; то же с `{"prompt":"Проще!"}` и `{"prompt":" simpler. "}`; с `{"prompt":"так будет проще"}`, `{"prompt":"/проще"}` и пустым вводом — одна строка `[consent check]`; код выхода — 0.

## Шаг 9. `HELP.md` — одним вопросом человеку

Показать и вписать с его «да» — текстом из `HELP.md` зеркала: раздел «Как я отвечаю» (перед «Новый чат — под каждую задачу»), правка пункта «впиши проверки» в «Безопасности» и строка «Ответил непонятно… Понял задачу не так…» в «Если что-то идёт не так».

## Шаг 10. Отпечаток

`base@48` → `base@49` в строке 3 `CLAUDE.md`. Человеку: новый вид ответов — с нового чата; проект под git с отдельной веткой знаний — после влития и обновления папки, где открываются чаты (там же — отложенная строка «только у меня», если была).

## Откат

Удалить строку `outputStyle` и файл `.claude/output-styles/plain.md`. Абзац «На языке человека» остаётся: правила содержания работают и без стиля.
