# Миграция 0004 — оценщик готового ответа, служебная строка о согласии и весь переход на base@43

> **Исполняется агентом ВНУТРИ боевого репозитория инстанса** с отпечатком `base@42`. Это **единственный путь** перехода 42→43: остальные части base@43 (все прочие блоки записи `## base@43` журнала) эта миграция тоже проводит — шаг 4. По заголовкам журнала base@43 не принимать: профилактика сверяет номера версий, и версия, принятая наполовину, больше не догонит вторую половину. Источник — публичное зеркало (`constructor/base/`). Знание — ADR-0054 (оценщик) и ADR, названные в прочих блоках.

## Что меняется и главный инвариант

1. **`.claude/`** — `hooks/consent_nudge.py`, `hooks/judge.py` и две записи в `settings.json`: `UserPromptSubmit` (служебная строка о согласии перед каждым ходом агента) и `Stop` (готовый ответ смотрит отдельная быстрая модель; нашла знание, которое агент не предложил записать, — возвращает его дописать одну строку-предложение). Свой след оценщик пишет в `tmp/knowledge-check/`.
2. **Проза** — правило «Просьба решена» и строка дерева `.claude/` в `CLAUDE.md`; раздел «Знание из разговора» в `methodology/ingest.md`; `methodology/bootstrap.md`; проверка «Проверка памяти проекта не работает» в `methodology/lint.md`; строки `HELP.md` — с «да» человека (шаг 6).
3. **Остальные части base@43** — по «Как принять» своих блоков журнала.

> **Инвариант миграции.** Меняется только СТАНДАРТ-слой: `.claude/`, `.gitignore` (строка `tmp/`, если её нет), `CLAUDE.md`, `methodology/*.md`, `HELP.md` (с «да»), отпечаток. `wiki/` (тела страниц), `raw/`, `STATE.md`, рабочие слои, чужие хуки и ключи в `.claude/` — байт-в-байт. Проверяется diff'ом (шаг 5). **Каждый шаг идемпотентен:** уже сделанное — не дублировать; прерванную миграцию можно запустить заново.

## Шаг 1. Входное состояние

Отпечаток (строка 3 `CLAUDE.md`) — `base@42`; иначе сначала догнать ленту до 42. Затем:
- `.claude/settings.json` есть → ветка B; нет (человек убрал папку) → ветка A.
- `disableAllHooks: true` в `settings.json` или `settings.local.json` → одной фразой человеку: «автоматические проверки в этом проекте выключены — проверка памяти работать не будет»; флаг не трогать, продолжать.
- `command -v claude` ничего не нашёл → запись `Stop` (оценщик) не ставить, только `UserPromptSubmit`; одной фразой человеку: «проверка моих ответов недоступна — нет команды `claude`; предлагать сохранить важное буду сам, но реже».

## Шаг 2A. Нет `settings.json`

Скопировать файлы, как в 2B, затем создать `.claude/settings.json` только с записями шага 2B. Хук свежести (`SessionStart`) без вопроса не восстанавливать — его убрал человек.

## Шаг 2B. Влить в существующий `settings.json` — СЛИЯНИЕ

Скопировать из зеркала `base/.claude/hooks/consent_nudge.py` и `base/.claude/hooks/judge.py` → `.claude/hooks/` (`chmod +x`). **Файл не перезаписывать:** добавить по объекту в массивы `hooks.UserPromptSubmit` и `hooks.Stop` (создать ключи, если нет), не трогая прочие ключи и уже стоящие хуки:

```json
{ "hooks": [ { "type": "command",
    "command": "command -v python3 >/dev/null 2>&1 && python3 \"$CLAUDE_PROJECT_DIR/.claude/hooks/consent_nudge.py\" || true" } ] }
```

```json
{ "hooks": [ { "type": "command", "timeout": 90,
    "command": "command -v python3 >/dev/null 2>&1 && python3 \"$CLAUDE_PROJECT_DIR/.claude/hooks/judge.py\" || true" } ] }
```

Команда с `consent_nudge.py` / `judge.py` уже стоит (в `settings.json` или `settings.local.json`) — не дублировать.

## Шаг 3. Проза оценщика

Из зеркала, сохраняя instance-контент (заполненные слоты, «О проекте», доменные разделы). Места — по заголовкам и тексту, не по номерам строк; уже вставленное — не дублировать:
1. `CLAUDE.md` — блок «Просьба решена — …» непосредственно перед `### После — фиксация принципа`; в пункт «Синтез знаний при закрытии единицы работы» после «Пропуск = вики отстаёт от того, что мы реально знаем.» — фраза про «Просьба решена» (хвост пункта со слотом не трогать — его заполнила механика класса); в «Растёт через» — «(д) …»; строку дерева `.claude/` — заменить.
2. `methodology/ingest.md` — указатель после строки «Запускается фразами…»; дописка к «**Тот же тезис**»; раздел «Знание из разговора» — в самый конец файла, после всех секций, включая добавленные механиками. Целиком не заменять.
3. `methodology/bootstrap.md` — описание `.claude/`.
4. `methodology/lint.md` — в «Только отчёт» пункт «Проверка памяти проекта не работает».

## Шаг 4. Остальные части base@43

Все прочие блоки записи `## base@43` журнала — каждый по своему «Как принять», кроме строк для `HELP.md`: они идут в шаг 6. Уже сделанное — не дублировать.

## Шаг 5. Проверить

- `git diff` — только `.claude/`, `.gitignore`, `CLAUDE.md`, `methodology/*.md`. `wiki/`, `raw/`, `STATE.md`, рабочие слои — нетронуты.
- `settings.json` — валидный JSON; `python3 .claude/hooks/consent_nudge.py < /dev/null` печатает одну строку; `echo '{}' | python3 .claude/hooks/judge.py` — тихо, код 0.
- Сам оценщик заработает со следующей сессии: хуки читаются при старте.

## Шаг 6. `HELP.md` — одним вопросом человеку

Памятку правит человек. Показать одним вопросом, без жаргона, все новые строки base@43: пункт «Контекст чата» (заменой) и «Мешает проверка памяти проекта» из этой части, а также строки из прочих блоков `## base@43`. Вписать то, на что он сказал «да» (нет нужного раздела — в конец файла). Отказ от всего или части — не вписывать, строка с датой в `wiki/log.md`; миграция считается завершённой.

## Шаг 7. Отпечаток

Строка 3 `CLAUDE.md`: `base@42` → `base@43`. Остальные части — без изменений.

## Откат

Выключить проверку без отката версии — пустой файл `.claude/knowledge-check.off` (человеку: «выключи проверку памяти»). Снять совсем — удалить обе записи из `settings.json` и файлы `consent_nudge.py`, `judge.py`; правило «Просьба решена» остаётся и работает само, слабее.
